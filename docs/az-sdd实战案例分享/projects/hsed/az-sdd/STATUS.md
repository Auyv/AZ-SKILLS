## 一期当前能力

- 通过 SPC 同步 RPC 提供对象创建/销毁、四项属性读写、加密、解密、签名、公钥导出和兼容保留的公钥导入入口。
- `ImportPublicKey` 当前固定返回 `PERMISSION_DENIED`，不访问或覆盖芯片。
- HSE 对象最多 8 个，句柄绑定创建连接，断线后自动清理。
- 45 个当前可用对象属性具有确定默认值；全部密钥槽位属性只读。
- CIU98 固定槽位 1～14：对称密钥 1～4，RSA1024 5/6，RSA2048 7/8，ECC256 9/10，SM2 11/12，SM9 13/14；15～24 保留。
- 生产 `debug=0` 校验 RSA1024、RSA2048、ECC256、SM2 固定公钥算法和长度；受控 `debug=1` 可修复这四类异常密钥对。
- SM2 原文签名使用 `USER_ID` 前 16 字节派生 ZA；三对象不同 USER_ID 的设备 OpenSSL 验签已通过。
- `hsed --test-spi` 是基础通信烟测，退出码为 0/2/3/4/5，不执行供应商全量 API 示例。

## 明确未实现

- 0010：程序退出时 SPI 引脚切换 GPIO 并设置低功耗电平。
- 0012：业务接口读取和首次配置 CHIP_ID；当前返回 `UNSUPPORTED`。
- 0013：公钥导入与受控覆盖；当前返回 `PERMISSION_DENIED`。
- 0014：对称密钥、SM9 等固定槽位的全量安全自动补齐。
- 私钥导入/导出、验签、业务密钥生成、密钥删除、独立摘要、随机数和固件升级接口。

## 交接关注项

1. 以 `az-sdd/SPEC.md` 的一期集合为功能入口，不再使用汇总型 `.spec.md`。
2. `az-sdd/ARCH.md` 的历史代码快照仍可能包含 2026-07-27 的旧结论，复现当前功能时不得覆盖最新单项规范。
3. 完整部署需同步 HSED、ABI 匹配的供应商 SO 和 INI。
4. GPIO41 WAKE 是否由底层代管仍需目标板确认。
5. 全算法实机覆盖和当前通信烟测的设备记录仍应持续补充到 `doc/hsed-handover.md`。
