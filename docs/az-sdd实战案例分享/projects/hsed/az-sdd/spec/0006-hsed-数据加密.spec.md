## Part 1：功能契约

### 用户目标

HSED 调用方能够选择明确的密码算法并使用该算法的固定密钥槽位，将完整二进制明文交给加密芯片处理，并获得与所选算法、模式、补位和 IV 一致的完整密文。

### 使用场景

1. 使用 AES128、TDES128、SM1 或 SM4 对业务数据进行对称加密。
2. 使用当前物料支持的 RSA1024、RSA2048、ECC256、SM2 或 SM9 公钥槽位进行非对称加密。
3. 多个业务进程同时请求加密，由 HSED 安全串行访问同一加密芯片。

### 输入与输出

| 项目 | 内容 |
|---|---|
| 输入 | 有效对象、`HsedAlgorithm`、完整二进制明文及其长度 |
| 对称配置 | 对应算法的 `KEY_ID`、模式、补位和按需设置的 IV |
| 非对称配置 | 对应算法的 `PUBLIC_KEY_ID` 及算法要求的补位或模式 |
| 输出 | 完整密文和实际长度，或统一失败结果 |

### 业务规则

- 每次加密必须显式指定算法，只读取该算法对应的属性组，不得回退到其他算法。
- 对称加密固定选择对应对称槽位；非对称加密固定选择对应公钥槽位，调用方不能改用私钥槽位。
- ECB 不使用 IV；CBC 必须提供符合算法长度要求的 IV；无意义或缺失的属性组合返回 `INVALID_PARAM`。
- 输入是可包含 `0x00` 的完整二进制数据，不按字符串结束符截断。
- 输入长度必须满足所选算法、补位、SPC 和当前物料的限制；超过限制返回 `DATA_TOO_LARGE`。
- 输出容量不足时返回 `DATA_TOO_LARGE` 并报告所需长度，不得返回截断密文。
- 当前物料不支持的算法、模式或补位返回 `UNSUPPORTED`，不得改用软件实现或其他算法。
- 同一对象在并发属性更新和加密时，只能使用一次调用开始前或完成后的完整属性组。
- 多线程调用必须安全，实际 SDK/芯片加密操作保持串行，响应不得串线。

### 使用流程

1. 调用方创建 HSE 对象，使用对象自带的固定密钥槽位并按需配置其他可写属性。
2. 调用方提交算法和完整明文。
3. HSED 校验对象、算法、槽位角色、属性组合、输入长度和输出容量。
4. 校验通过后由芯片完成加密，返回完整密文；失败时返回统一错误且不返回部分密文。

### 特殊情况

- 使用哈希算法或 `NONE` 请求加密：返回 `UNSUPPORTED`。
- 密钥槽位不存在：返回 `KEY_NOT_FOUND`。
- 槽位算法或角色不匹配：返回 `INVALID_PARAM` 或 `PERMISSION_DENIED`。
- 芯片忙、超时、断开或发生未知错误：分别返回 `BUSY`、`TIMEOUT`、`DEVICE_UNAVAILABLE` 或 `DEVICE_ERROR`。
- 空输入在 SPC 入口返回 `INVALID_PARAM`，不调用芯片。

## Part 2：验收契约

### 验收标准

- [ ] [001] 每种当前物料声明支持的对称加密算法均可使用正确槽位和属性完成已知向量测试。
- [ ] [002] 每种当前物料声明支持的非对称加密算法均只使用对应公钥槽位并完成成功测试。
- [ ] [003] 明文包含 `0x00` 时按完整长度处理，解密后可恢复全部原文。
- [ ] [004] 算法与属性组不匹配时明确失败；调用方不能把固定公钥槽位改为私钥槽位。
- [ ] [005] CBC 缺少或使用错误长度 IV 时返回 `INVALID_PARAM`；ECB 不依赖 IV。
- [ ] [006] 输入或输出超过限制时返回 `DATA_TOO_LARGE`，不截断且不返回伪成功。
- [ ] [007] 不支持的算法、模式或补位返回 `UNSUPPORTED`，不发生软件回退。
- [ ] [008] 多线程并发加密时所有密文与原请求一一对应，芯片调用保持串行。
- [ ] [009] 芯片故障、忙和超时分别转换为稳定的统一结果。

### 测试用例

#### MT001 对称已知向量
- **测试步骤**：为各受支持对称算法配置合法槽位、模式、补位和 IV，执行标准或供应商确认的已知向量。
- **预期结果**：密文与期望值一致。
- **验收标准**：[001]

#### MT002 非对称公钥加密
- **测试步骤**：使用各受支持非对称算法的固定公钥槽位加密合法长度明文。
- **预期结果**：加密成功；未访问私钥槽位。
- **验收标准**：[002]

#### MT003 二进制与容量边界
- **测试步骤**：加密包含多个 `0x00` 的明文；再使用超限输入和不足输出容量。
- **预期结果**：合法输入完整处理；超限场景返回 `DATA_TOO_LARGE` 且无截断成功。
- **验收标准**：[003] [006]

#### MT004 属性、槽位与能力拒绝
- **测试步骤**：构造空输入、错误 IV、算法属性错配及物料不支持的算法，并尝试修改固定公钥槽位。
- **预期结果**：分别返回明确失败；固定槽位修改返回 `PERMISSION_DENIED`；无软件回退。
- **验收标准**：[004] [005] [007]

#### MT005 并发与设备故障
- **测试步骤**：至少 8 个线程使用不同对象和明文并发加密，并分别注入忙、超时和断开错误。
- **预期结果**：响应不串线、芯片调用串行；错误映射稳定。
- **验收标准**：[008] [009]
