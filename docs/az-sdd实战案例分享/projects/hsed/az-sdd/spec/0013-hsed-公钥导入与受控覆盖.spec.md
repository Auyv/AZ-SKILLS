## Part 1：功能契约

### 用户目标

授权的密钥管理员可以向允许的业务公钥槽位导入算法匹配的公钥，并在明确授权且安全的条件下覆盖已有公钥。

### 业务规则

- 只允许导入公钥，禁止导入私钥。
- 固定槽位 1～24 默认受保护；未建立独立业务槽位和权限模型前不得开放导入。
- 公钥格式、长度、算法和槽位角色必须匹配。
- 禁止覆盖时，已占用槽位返回 `KEY_OCCUPIED`。
- 允许覆盖时仍须同时满足管理权限、目标槽位允许覆盖且无活动使用；否则返回 `PERMISSION_DENIED` 或 `BUSY`。
- 导入失败时原槽位内容保持不变；成功后可立即导出并逐字节核对。
- 当前代码对合法对象的所有导入请求返回 `PERMISSION_DENIED`，不访问芯片。本规范批准并实现前不得改变该行为。

## Part 2：验收契约

### 验收标准

- [ ] [001] 授权调用方可向允许的空闲公钥槽位导入合法 BIN 公钥并完整导出核对。
- [ ] [002] 私钥、错误算法、错误角色、错误格式或错误长度均被拒绝。
- [ ] [003] 禁止覆盖、无权限或有活动使用时原密钥保持不变。
- [ ] [004] 并发导入同一槽位时最多一个完整操作成功，不产生部分写入。

### 测试用例

#### MT001 合法导入
- **测试步骤**：向允许的空闲业务公钥槽位导入算法匹配的公钥，再导出比较。
- **预期结果**：导入成功且内容一致。
- **验收标准**：[001]

#### MT002 权限和覆盖保护
- **测试步骤**：分别提交私钥、错误格式、禁止覆盖、无权限、有活动使用及并发覆盖请求。
- **预期结果**：非法请求全部失败且原值不变；并发操作无部分写入。
- **验收标准**：[002] [003] [004]
