## Part 1：功能契约

### 用户目标

测试人员可在目标设备上执行 `hsed --test-spi`，以确认 HSED 配置的 SPI 设备能够与已连接的 CIU98 加密芯片完成真实通信。测试结果应清晰表明成功或失败原因，且测试不启动正常 HSED SPC 服务、完成后立即退出。

### 使用场景

1. 首次部署 HSED 到目标设备后，测试人员确认 CIU98 硬件接线、SPI 设备节点和基础通信是否正常。
2. 修改 SPI 设备路径配置、目标机内核或驱动后，测试人员重新确认 CIU98 通信状态。
3. 正常 HSED 服务无法使用芯片时，测试人员先单独运行自检指令定位 SPI 设备或芯片连接问题。

### 输入与输出

| 项目 | 内容 |
|---|---|
| 启动方式 | `hsed --test-spi [--cfg <ini路径>]` |
| SPI 设备路径 | 传入 `--cfg` 时从指定 INI 配置读取；未传入 `--cfg` 时使用默认值 `/dev/spidev1.0` |
| 外部对象 | 已连接并可响应的 CIU98 加密芯片 |
| 成功输出 | 显示实际使用的 SPI 设备路径及明确的 CIU98 通信自检通过日志 |
| 失败输出 | 明确显示实际使用的 SPI 设备路径、失败阶段和可辨识的失败原因 |
| 进程结果 | 成功为 0；命令格式错误为 2；配置错误为 3；设备占用为 4；其他自检错误为 5 |

### 业务规则

- `--test-spi` 是独立自检模式；执行时不得启动正常 HSED SPC 服务，也不得接受或处理正常业务请求。
- 自检传入 `--cfg` 时必须使用指定 INI 中的 SPI 设备路径；未传入 `--cfg` 时必须使用默认路径 `/dev/spidev1.0`，并在输出中说明实际使用的路径。
- 自检通过的必要条件是：能够打开目标 SPI 设备，并与 CIU98 完成一次真实、可确认成功的只读通信，获得芯片有效响应。
- 仅成功打开 SPI 设备、仅完成参数设置或仅确认设备节点存在，均不得视为自检通过。
- 自检不得执行密钥写入、密钥覆盖、CHIP_ID/SE ID 写入、认证密钥更新、固件升级或其他会永久改变 CIU98 状态的操作。
- 自检完成后立即结束进程；无论成功或失败，都不得转入正常 HSED SPC 服务模式。
- 正常 HSED SPC 服务已运行时，自检应拒绝执行并明确提示服务占用，避免同时访问同一加密芯片。

### 使用流程

1. 测试人员确认 CIU98 已连接，且正常 HSED SPC 服务未运行。
2. 测试人员按需准备包含 SPI 设备路径的 INI 文件；未使用 INI 时使用默认路径 `/dev/spidev1.0`。
3. 测试人员在目标设备上执行 `hsed --test-spi`，或执行 `hsed --test-spi --cfg <ini路径>`。
4. HSED 显示实际使用的 SPI 设备路径，并执行 CIU98 真实通信自检。
5. 通信成功时，HSED 输出通过信息并以退出码 0 结束；任一阶段失败时，输出失败原因并以非 0 退出码结束。

### 特殊情况

- 未传入 `--cfg`：使用默认路径 `/dev/spidev1.0` 继续自检，并明确显示该路径来自默认值。
- 传入 `--cfg` 但 INI 文件不存在、无法读取、路径项缺失或为空：自检失败，输出配置文件和配置原因；不得静默回退到默认路径。
- INI 中配置的路径不存在、不可访问或不是可用 SPI 设备：自检失败，输出配置路径及打开失败原因。
- SPI 设备可打开但 CIU98 无响应、响应无效或通信超时：自检失败，明确说明为芯片通信失败，不得报告通过。
- SPI 配置不兼容：自检失败，输出配置失败原因，不得继续执行可能导致误判的通信操作。
- 正常 HSED SPC 服务正在运行：自检拒绝执行，输出服务占用提示并以非 0 退出。
- 指令不含 `--test-spi`：保持既有 HSED 启动行为，不因本功能改变。
- 参数排列不符合 `hsed --test-spi [--cfg <ini路径>]`：打印用法并以退出码 2 结束，不进入正常服务或自检。

## Part 2：验收契约

### 验收标准

- [ ] [001] 未传入 `--cfg` 时，执行 `hsed --test-spi` 使用 `/dev/spidev1.0`，并在输出中显示实际使用的默认路径。
- [ ] [002] 传入 `--cfg <ini路径>` 且 INI 中配置有效 SPI 路径时，自检使用该配置路径，并在输出中显示实际使用的配置路径。
- [ ] [003] 传入 `--cfg` 但 INI 文件不可读、路径项缺失/为空，或配置路径不存在、不可访问或不可用时，自检以非 0 退出，并输出对应配置或打开失败原因。
- [ ] [004] 当 `/dev/spidev1.0` 与 CIU98 通信正常时，自检完成真实芯片通信，输出“CIU98 通信自检通过”并以退出码 0 结束。
- [ ] [005] 当 SPI 设备可打开但 CIU98 不响应、响应无效或通信超时时，自检以非 0 退出，明确报告芯片通信失败，且不得输出通过信息。
- [ ] [006] 自检过程中不得写入或覆盖密钥、写入 CHIP_ID/SE ID、更新认证密钥或执行固件升级。
- [ ] [007] 执行 `hsed --test-spi` 时不启动正常 HSED SPC 服务；自检结束后进程立即退出。
- [ ] [008] 正常 HSED SPC 服务已经运行时，自检被拒绝并以非 0 退出，且输出服务占用提示。
- [ ] [009] 不带 `--test-spi` 的 HSED 启动行为与本功能增加前保持一致。
- [ ] [010] 自检成功、命令格式错误、配置错误、设备占用及其他自检错误分别返回 0、2、3、4、5。
- [ ] [011] 自检只执行基础通信烟测，不执行供应商全量 API 示例测试。

### 测试用例

#### MT001 默认路径真实通信自检
- **测试步骤**：不传入 `--cfg`，确保 CIU98 正常连接且正常 HSED SPC 服务未运行；执行 `hsed --test-spi`。
- **预期结果**：输出显示使用 `/dev/spidev1.0` 默认路径；完成真实 CIU98 通信；输出“CIU98 通信自检通过”；退出码为 0。
- **验收标准**：[001] [004] [007]

#### MT002 配置路径优先
- **测试步骤**：在 INI 中配置可用 SPI 路径，确保该路径可与 CIU98 正常通信；执行 `hsed --test-spi --cfg <ini路径>`。
- **预期结果**：输出显示使用 INI 配置路径而非默认路径；通信自检通过；退出码为 0。
- **验收标准**：[002] [004]

#### MT003 无效设备路径
- **测试步骤**：分别传入不存在的 INI、缺少路径项的 INI、以及配置不存在或无访问权限设备路径的 INI；执行 `hsed --test-spi --cfg <ini路径>`。
- **预期结果**：输出包含配置路径和打开失败原因；不输出通过信息；退出码非 0。
- **验收标准**：[003]

#### MT004 芯片无响应
- **测试步骤**：保持 SPI 设备节点可打开，但使 CIU98 无法响应，例如断开芯片连接或使用已确认的非响应硬件状态；执行 `hsed --test-spi`。
- **预期结果**：输出说明芯片通信失败或超时；不输出通过信息；退出码非 0。
- **验收标准**：[005]

#### MT005 安全边界
- **测试步骤**：在测试 CIU98 样片上执行 `hsed --test-spi` 前后，核对密钥、CHIP_ID/SE ID、认证密钥和固件版本状态。
- **预期结果**：自检前后所有核对项均未改变。
- **验收标准**：[006]

#### MT006 独立运行与服务占用
- **测试步骤**：先在未启动正常 HSED SPC 服务时执行 `hsed --test-spi`；再启动正常服务后再次执行相同指令。
- **预期结果**：首次自检结束后不保留正常 SPC 服务；第二次被拒绝并显示服务占用提示，退出码非 0。
- **验收标准**：[007] [008]

#### MT007 正常启动兼容性
- **测试步骤**：不带 `--test-spi` 启动 HSED。
- **预期结果**：行为与新增本功能前一致，不进入自检模式。
- **验收标准**：[009]

#### MT008 退出码与烟测边界
- **测试步骤**：分别执行成功自检、错误参数、无效配置、服务占用和通信失败场景，并检查日志中实际执行的测试范围。
- **预期结果**：退出码依次为 0、2、3、4、5；自检只完成动态库装载、SPI 配置和 CIU98 基础通信，不运行供应商全量 API 示例。
- **验收标准**：[010] [011]

## Part 3：非功能需求与实现影响提示

### 非功能需求

| 类型 | 用户可感知要求 | 验收方式 |
|---|---|---|
| 安全性 | 自检只进行无持久状态变更的通信验证 | 执行 MT005 |
| 隔离性 | 自检不启动正常服务，正常服务运行时拒绝并发自检 | 执行 MT006 |
| 可诊断性 | 成功与失败均展示实际路径、失败阶段和结果 | 执行 MT001 至 MT004 |
| 配置兼容性 | `--cfg` 可指定 INI 覆盖路径，未传入时稳定使用默认值 | 执行 MT001、MT002、MT003 |

### 实现影响提示

| 类型 | 说明 |
|---|---|
| 命令行行为 | 增加 `--test-spi [--cfg <ini路径>]` 自检模式，且不得影响无参数启动行为 |
| 配置 | `--cfg` 指定 INI 中的 SPI 设备路径；未传入时使用 `/dev/spidev1.0` 默认值 |
| 外部依赖 | 依赖目标设备 SPI 节点及已连接的 CIU98 加密芯片 |
| 运行互斥 | 自检与正常 HSED SPC 服务不能同时直接访问芯片 |
| 详细技术方案 | 已由关联的功能级技术规范定义 |
