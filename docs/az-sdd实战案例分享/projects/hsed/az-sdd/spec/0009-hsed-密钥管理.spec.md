## Part 1：功能契约

### 用户目标

调用方可以从 HSED 固定非对称公钥槽位导出公钥，用于密钥分发或外部验签，同时不能读取或导出私钥。

### 输入与输出

| 项目 | 内容 |
|---|---|
| 输入 | 当前连接的对象句柄、RSA1024/RSA2048/ECC256/SM2/SM9 算法标识、输出缓冲区容量 |
| 输出 | 对应固定公钥槽位中的 BIN 原始公钥及实际长度，或统一失败结果 |

### 业务规则

- `key_id` 只表示 CIU98 硬件槽位，不表示用户、连接、对象或会话。
- 公钥导出只接受非对称算法，并使用 0011 规定的固定公钥槽位。
- 调用方不能修改公钥槽位引用，也不能要求导出私钥槽位内容。
- 输出容量不足时返回 `DATA_TOO_LARGE`，不得将截断数据报告为成功。
- 算法、槽位类型或设备状态异常时明确失败，不得切换到其他槽位或软件密钥。
- 一期保留 `ImportPublicKey` RPC 名称，但所有合法对象的导入请求均返回 `PERMISSION_DENIED`，且不访问芯片。未来公钥导入需求独立记录在 0013。

## Part 2：验收契约

### 验收标准

- [ ] [001] 每种已预置且受支持的非对称公钥可从对应固定槽位完整导出。
- [ ] [002] 对称算法、公私钥角色错误或不存在槽位明确失败，不返回其他槽位数据。
- [ ] [003] 输出容量不足时返回 `DATA_TOO_LARGE`，不返回截断成功结果。
- [ ] [004] 私钥不能通过任何一期接口导出、读取或写入日志。
- [ ] [005] `ImportPublicKey` 对合法对象返回 `PERMISSION_DENIED`，固定槽位内容不变。

### 测试用例

#### MT001 固定槽位公钥导出
- **测试步骤**：分别导出已预置的非对称算法公钥并记录长度和内容。
- **预期结果**：公钥来自对应固定槽位，格式和长度符合算法要求。
- **验收标准**：[001]

#### MT002 错误算法与容量
- **测试步骤**：使用对称算法请求导出，并使用不足容量导出有效公钥。
- **预期结果**：错误算法失败；容量不足返回 `DATA_TOO_LARGE`，不报告截断成功。
- **验收标准**：[002] [003]

#### MT003 私钥与导入保护
- **测试步骤**：检查所有公共 RPC；调用 `ImportPublicKey` 并再次导出原公钥比较。
- **预期结果**：不存在私钥导出能力；导入返回 `PERMISSION_DENIED`，原公钥保持不变。
- **验收标准**：[004] [005]
