## Part 1：功能契约

### 用户目标

调用方创建对象后，可以直接获得确定的密码属性默认值和只读密钥槽位，不需要猜测或在每次调用前重复配置槽位。

### 默认槽位

| 算法 | 固定槽位 |
|---|---|
| AES128 | 对称密钥 1 |
| TDES128 | 对称密钥 2 |
| SM1 | 对称密钥 3 |
| SM4 | 对称密钥 4 |
| RSA1024 | 公钥 5，私钥 6 |
| RSA2048 | 公钥 7，私钥 8 |
| ECC256 | 公钥 9，私钥 10 |
| SM2 | 公钥 11，私钥 12 |
| SM9 | 公钥 13，私钥 14 |
| 保留区 | 15～24，不由一期客户端使用 |

### 属性默认值

| 属性类别 | 默认值 |
|---|---|
| 所有 `KEY_ID` / `PUBLIC_KEY_ID` / `PRIVATE_KEY_ID` | 上表固定槽位，只读 |
| AES128/TDES128/SM1/SM4 模式 | ECB |
| AES128/TDES128/SM1/SM4 填充 | NONE |
| RSA1024/RSA2048 填充 | PKCS1 |
| RSA1024/RSA2048/ECC256 摘要 | SHA256 |
| SM2/SM9 摘要 | SM3 |
| 所有签名输入模式 | MESSAGE |
| SM9 模式 | STREAM |
| 所有公钥格式 | BIN |
| `USER_ID` | 空，长度 0 |
| 四种对称 IV | 未设置 |

当前接口模型声明 46 个属性标识，其中 `CHIP_ID` 读写尚未实现并独立记录在 0012；本规范约束其余 45 个当前可用属性的默认值与权限。

### 业务规则

- 新对象必须一次装载本规范的全部默认值；不同对象读取结果一致。
- 所有密钥槽位属性只读，任何修改请求返回 `PERMISSION_DENIED`。
- `ImportPublicKey` 不得覆盖槽位 1～24，具体一期行为见 0009。
- 生产配置 `debug=0` 时，HSED 启动前校验 RSA1024、RSA2048、ECC256、SM2 固定公钥槽位的算法和长度；异常时不开放服务。
- 受控维护配置 `debug=1` 时，可重新建立上述四类异常非对称密钥对；修复后必须再次校验，通过后才能开放服务。
- 调试修复可能覆盖原槽位密钥，仅限维护环境；普通客户端不能触发。
- 对称槽位 1～4 和 SM9 槽位 13/14 的自动生成不属于一期，后续需求独立记录在 0014。
- 当前芯片不能查询私钥内容或角色；启动校验只以可导出的公钥算法和长度作为密钥对类型判据，不得宣称已读取私钥。

## Part 2：验收契约

### 验收标准

- [ ] [001] 新对象可读取 45 个当前可用属性，初始值与本规范一致。
- [ ] [002] 不同对象的固定槽位和其他默认值一致，后续可写属性修改互不影响。
- [ ] [003] 修改任意密钥槽位属性返回 `PERMISSION_DENIED`，原值不变。
- [ ] [004] `debug=0` 时四类固定非对称公钥槽位正确则服务启动，异常则拒绝开放服务。
- [ ] [005] `debug=1` 时可修复 RSA1024、RSA2048、ECC256、SM2 异常密钥对，修复后复查通过。
- [ ] [006] 普通客户端不能触发修复或覆盖固定密钥。
- [ ] [007] 对称和 SM9 自动补齐未被伪装为一期已实现能力。

### 测试用例

#### MT001 默认值完整性
- **测试步骤**：创建对象，逐项读取 45 个当前可用属性。
- **预期结果**：全部读取成功，默认值与本规范一致；读取 CHIP_ID 按 0012 当前状态返回 `UNSUPPORTED`。
- **验收标准**：[001]

#### MT002 对象独立与槽位只读
- **测试步骤**：创建两个对象，读取固定槽位；修改其中一个对象的可写属性，并尝试修改全部密钥槽位属性。
- **预期结果**：固定槽位一致且修改均返回 `PERMISSION_DENIED`；可写属性只影响目标对象。
- **验收标准**：[002] [003]

#### MT003 生产启动校验
- **测试步骤**：在四类非对称槽位正确和算法/长度错误两种状态下，以 `debug=0` 启动。
- **预期结果**：正确状态启动；异常状态拒绝开放 SPC 服务，且不覆盖密钥。
- **验收标准**：[004]

#### MT004 受控修复
- **测试步骤**：在受控设备构造可修复的异常非对称槽位，以 `debug=1` 启动后再以 `debug=0` 启动并导出公钥验证。
- **预期结果**：仅调试配置执行修复；四类槽位复查通过；生产配置可稳定复用。
- **验收标准**：[005] [006]

#### MT005 未实现边界
- **测试步骤**：使用空的对称或 SM9 固定槽位启动，检查是否发生自动生成。
- **预期结果**：一期不执行对称或 SM9 自动补齐，不报告该能力已完成。
- **验收标准**：[007]
