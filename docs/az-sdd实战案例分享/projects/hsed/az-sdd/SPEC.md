# HSED 功能规范集合

## 文档定位

本文件是 HSED 功能规范的唯一集合入口。`az-sdd/spec/` 中每个 `.spec.md` 只描述一个独立功能；本文件负责汇总规范状态、一期正式交付集合和后续未实现集合，不再创建“一期完整功能规范”之类的汇总 `.spec.md`。

当前状态基于 2026-08-02 的 HSED 代码、`doc/hsed.xlsx` 接口模型和设备验证记录逆向订正。若旧审核记录、旧架构快照或生成注释与当前代码行为冲突，以对应单项规范中标记的“代码基线订正”内容为准。

## 一期正式功能规范集合

一期正式交付由下列单项规范共同组成：

| 编号 | 一期交付能力 | 当前代码边界 |
|---|---|---|
| 0001 | 对外算法、结果码和属性标识 | 生成接口与 BSC 公共标识保持一致 |
| 0002 | SM2 USER_ID 与 ZA | USER_ID 至少 16 字节，只使用前 16 字节；SM2 摘要模式不支持 |
| 0003 | SPI 通信自检 | 仅做 CIU98 基础通信烟测，不等同供应商全量 API 测试 |
| 0004 | 统一硬件密码能力 | 11 项 SPC RPC 通过统一能力层串行访问 CIU98 |
| 0005 | 对象及对象属性管理 | 最多 8 个对象，句柄绑定连接；CHIP_ID 不包含在内 |
| 0006 | 数据加密 | 使用固定对称或公钥槽位；实际成功依赖芯片已预置匹配密钥 |
| 0007 | 数据解密 | 使用固定对称或私钥槽位；实际成功依赖芯片已预置匹配密钥 |
| 0008 | 数据签名 | 非对称签名；SM2+SM3 原文带 ZA 已完成设备验签 |
| 0009 | 公钥导出 | 导出固定非对称公钥；公钥导入固定拒绝 |
| 0011 | 默认属性与固定槽位 | 45 个当前可用属性；固定槽 1～14；四类非对称槽位启动校验和受控修复 |

一期公共 RPC 仍为 11 项：`HseCreate`、`HseDestroy`、`SetPropertyInt`、`SetPropertyBytes`、`GetPropertyInt`、`GetPropertyBytes`、`Encrypt`、`Decrypt`、`Sign`、`ExportPublicKey`、`ImportPublicKey`。其中 `ImportPublicKey` 是兼容保留入口，当前业务结果固定为 `PERMISSION_DENIED`。

一期明确不提供私钥导入/导出、验签、业务密钥生成、密钥删除、独立摘要、随机数和固件升级接口。

## 未实现规范集合

下列规范不属于一期正式交付，但作为独立需求保留，后续可以分别审核、设计和实现：

| 编号 | 未实现内容 | 当前行为 |
|---|---|---|
| 0010 | 程序退出时 SPI 转 GPIO 并设置低功耗电平 | 当前 HSED 工程未实现退出引脚低功耗收尾 |
| 0012 | CHIP_ID 读取和首次配置 | 对象属性读写返回 `UNSUPPORTED`；自检读取芯片信息不等于开放该业务属性 |
| 0013 | 公钥导入和受控覆盖 | `ImportPublicKey` 返回 `PERMISSION_DENIED`，不访问芯片 |
| 0014 | 对称密钥和 SM9 等固定槽位全量自动补齐 | 一期只校验/修复 RSA1024、RSA2048、ECC256、SM2 非对称密钥对 |

## 状态说明

- **一期已实现**：功能行为已存在于一期代码；规范已按当前实现订正。该状态不表示所有算法组合都已完成穷举实机验证。
- **未实现**：需求作为独立规范保留，当前代码不提供该功能；不得纳入一期验收或对外承诺。
- 后续若变更产品行为，应先修改对应单项规范并审核，不能只修改本集合表。

## 复现与交接口径

- 功能复现：先读取本文件的“一期正式功能规范集合”，再逐项读取对应 `.spec.md`。
- 技术实现：结合 `az-sdd/ARCH.md`、功能级 `.arch.md` 和 `doc/hsed-handover.md`；其中历史代码快照不得覆盖本文件的 2026-08-02 基线。
- 对外接口：以 `doc/hsed.xlsx` 及其生成文件为模型；若生成注释与当前行为不一致，应先修正模型，不得据旧注释扩大一期能力。
