## 一、任务目标

在不恢复 GUI、不引入网络或新运行时依赖的前提下，实现单次执行结构化捕获、最近一次日志 UTF-8 非覆盖导出、`Ctrl+P` TUI 触发，以及 Notepad++ 优先、Notepad 回退的编辑器打开策略。文件生成与编辑器打开结果分别反馈，且保持当前实例隔离。

### 轻量设计决策

- 新增 `internal/logexport`，只负责单次执行快照、文档生成和编辑器打开，不承担 TUI 状态。
- `terminal.Model` 为每个实例持有独立 active map 与 last snapshot，不创建跨进程共享状态。
- 后台任务依据 `task.Event` 到达顺序记录 stdout/stderr；交互任务使用共享顺序记录器回写。
- 导出目录使用当前用户本地数据目录下的 `azKits/logs`，测试可注入其他目录。
- 文件名包含结束时间、脚本 alias 和唯一后缀，使用排他创建，禁止覆盖。
- 编辑器使用标准库进程启动，不增加第三方依赖；启动失败不回滚已写入文档。
