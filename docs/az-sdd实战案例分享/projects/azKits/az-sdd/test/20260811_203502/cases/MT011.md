## 测试要求

1. 在两个终端分别执行 `run_azKits_go.bat`，形成两个独立实例。
2. 只在实例 A 成功执行一个命令。
3. 在实例 A 输入为空时按 `↑`，确认能看到刚执行的命令。
4. 在实例 B 输入为空时按 `↑`，确认不会出现实例 A 的命令。
5. 关闭实例 A，重新启动后按 `↑`，确认历史为空。

## 预期结果

命令历史只存在于当前 TUI 进程；不跨实例共享，进程重启后不保留。
