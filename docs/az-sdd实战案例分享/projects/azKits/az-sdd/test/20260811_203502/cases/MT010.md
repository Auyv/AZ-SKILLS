## 测试要求

1. 执行 `run_azKits_go.bat` 启动 TUI。
2. 输入并成功执行两个不同的斜杠命令，确认每次成功启动后输入行立即为空。
3. 连续按 `↑`，确认依次出现较新的、较旧的命令，且不会越过最旧记录。
4. 连续按 `↓`，确认依次返回较新命令，并在越过最新记录后恢复空输入。
5. 从历史调出一个命令，编辑后按 `↑`，确认可重新取回最新历史；再按 `Enter` 重复执行。
6. 输入不存在的命令并按 `Enter`，确认输入保留，且该命令不进入历史。
7. 按 `Ctrl+C` 关闭当前实例，确认终端正常恢复。

## 预期结果

成功命令清空输入并进入历史；失败输入保留且不入历史；上下键边界、编辑和重复执行符合 0012 规范。
