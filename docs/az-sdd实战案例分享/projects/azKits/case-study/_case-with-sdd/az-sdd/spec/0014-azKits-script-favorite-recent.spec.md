## 一、功能契约

### 1.1 功能目标

在 azKits TUI 中为用户提供脚本收藏与最近使用两个快捷入口，使用户可以用最少按键再次触发经常使用或最近使用过的脚本：

- 用户可将常用脚本标记为收藏，收藏脚本在斜杠候选列表中置顶并带收藏标识，且跨终端实例保持一致。
- 系统按最近成功启动时间记录最近使用脚本，同一脚本只保留最近一次，支持一键再次触发。
- 收藏与最近使用记录的失效条目不得导致启动失败，需自动降级处理。

### 1.2 目标用户

- 每天反复运行少量固定脚本的测试人员，希望收藏后直接触发。
- 同时运行多个 azKits 终端实例、希望不同实例共享收藏偏好的用户。
- 需要快速重跑刚执行过脚本的开发、测试人员。

### 1.3 名词定义

| 名词 | 定义 |
|------|------|
| 收藏 | 用户通过 `/fav <alias>` 主动标记的脚本，状态持久化，跨实例共享 |
| 最近使用 | 当前实例内最近一次成功启动的脚本记录，仅本次实例有效 |
| 收藏标识 | 候选列表中标识收藏状态的符号（如 ★） |
| 最近使用标识 | 候选列表中标识最近使用状态的符号（如 ↺） |

### 1.4 使用场景

#### 场景 A：收藏常用脚本

用户输入 `/fav device-init`，该脚本被收藏并在候选列表置顶显示收藏标识；在另一个终端实例中启动 azKits 后，该脚本仍保持收藏。

#### 场景 B：快速重跑最近脚本

用户刚成功运行过「回归测试」，再次输入 `/` 时该脚本出现在最近使用区域顶部，直接按 `Enter` 即可再次触发。

#### 场景 C：搜索时优先看到常用脚本

用户输入 `/reg` 查询时，收藏与最近使用的匹配脚本仍排在普通匹配结果之前，减少按键次数。

#### 场景 D：收藏脚本被删除或重命名

脚本从 YAML 中被删除或重命名后，其收藏与最近使用记录不导致启动失败；候选列表不再展示失效条目，并给出降级提示。

### 1.5 用户操作流程

1. 用户在 TUI 输入 `/fav <alias>` 切换目标脚本收藏状态。
2. azKits 更新收藏记录并给出「已收藏 / 已取消收藏」反馈。
3. 用户输入 `/`，候选列表顶部先显示收藏脚本，其次按最近使用排序，再按原匹配规则排列。
4. 用户用 `↑`、`↓` 移动选择，按 `Enter` 运行目标脚本。
5. 脚本成功启动后，写入当前实例的最近使用记录并清空输入行。

### 1.6 输入项

| 输入 | 说明 |
|------|------|
| `/fav <alias>` | 斜杠命令，`alias` 为当前入口内唯一脚本别名，切换收藏状态 |
| `/` | 唤起候选列表，展示收藏、最近使用及全部启用脚本 |
| 普通查询文本 | 继续过滤候选，收藏与最近使用脚本置顶 |

### 1.7 输出项

- 收藏状态切换的明确反馈（已收藏 / 已取消收藏 / 无效别名提示）。
- 候选列表中带收藏与最近使用标识的脚本行，包含脚本名称、功能简述与状态。
- `list` 输出中对收藏脚本的标识。
- 空态时友好提示。

### 1.8 功能范围

#### 本功能包含

- 通过 `/fav <alias>` 切换脚本收藏状态，支持重复切换。
- 收藏状态跨终端实例保持一致并落盘持久化。
- 最近使用记录按最近成功启动时间排序，同一脚本只保留最近一次，仅本次实例有效、不落盘。
- 斜杠候选列表置顶规则：收藏 > 最近使用 > 原匹配规则，收藏且最近使用的脚本去重。
- 候选同时显示收藏/最近使用标识、脚本名称、功能简述与状态。
- 非空查询时收藏与最近使用脚本仍置顶于匹配结果顶部。
- `list` 标识收藏脚本；`run <alias>` 对收藏/最近使用脚本同样可用。
- 失效脚本的收藏与最近使用记录自动降级，不导致启动失败。
- 无收藏或无可用脚本时的友好空态提示。
- 500 个启用脚本下候选更新不超过 50 毫秒；离线与中文环境下全部可用。

#### 本功能不包含

- 新增任何鼠标操作或图形界面入口。
- 新增 ↑/↓/Tab/Enter/Esc 之外的脚本触发按键（收藏切换通过斜杠命令完成）。
- 最近使用记录跨实例共享或落盘持久化。
- 修改脚本触发、配置校验、命令历史等既有交互规则。
- 收藏状态的云端同步或网络依赖。

### 1.9 展示规则

#### 候选排序

1. 输入 `/`（空查询）时，候选顶部先显示收藏脚本，其次按最近使用排序，再按原匹配规则（YAML 顺序）排列。
2. 收藏且最近使用的脚本只出现一次，置于收藏区域。
3. 非空查询时，匹配结果中收藏与最近使用脚本仍置顶于普通匹配结果之前。
4. 同一区域内部按 YAML 配置顺序稳定排序。

#### 候选行内容

每个候选至少显示：

| 内容 | 说明 |
|------|------|
| 收藏标识 | 收藏脚本显示 ★，未收藏不显示 |
| 最近使用标识 | 最近使用脚本显示 ↺ |
| 斜杠命令 | 唯一命令别名 |
| 脚本名称 | 方便识别，支持中文 |
| 功能简述 | 执行前说明用途 |
| 当前状态 | 就绪 / 运行中 / 成功 / 失败 |

### 1.10 收藏与最近使用生命周期

| 项目 | 收藏 | 最近使用 |
|------|------|----------|
| 触发方式 | 用户主动 `/fav <alias>` | 脚本成功启动时自动记录 |
| 作用域 | 跨终端实例共享 | 仅当前实例 |
| 持久化 | 落盘，重启后保留 | 不落盘，重启后为空 |
| 更新规则 | 用户切换 | 按最近成功启动时间，同一脚本只保留最近一次 |
| 失效降级 | 脚本删除/重命名后自动隐藏，不影响启动 | 同左 |

### 1.11 特殊情况与处理

| 情况 | 用户可见行为 |
|------|--------------|
| `/fav` 后不带别名或别名不存在 | 显示明确提示，不改变任何收藏状态 |
| `/fav` 脚本已收藏 | 取消收藏并提示「已取消收藏」 |
| `/fav` 脚本未收藏 | 收藏并提示「已收藏」 |
| 收藏脚本从 YAML 删除或重命名 | 不导致启动失败，候选列表隐藏失效条目，必要时提示记录已失效 |
| 无任何收藏脚本 | 候选列表正常显示最近使用与全部脚本，不显示空收藏区 |
| 当前入口没有启用脚本 | 显示「当前没有可用脚本」友好提示 |
| 500 个启用脚本 | 每次有效输入后候选更新不超过 50 毫秒 |
| 脚本正在运行 | 显示「运行中」，不重复启动 |
| 中文输入法组词、选字、上屏 | 期间不得误执行脚本；上屏后才更新候选 |
| 断网环境 | 收藏、最近使用、候选、执行全部可用 |
| 多个实例同时运行 | 各自收藏一致；各自最近使用独立 |

### 2.2 人工测试用例

#### MT001 收藏切换与反馈验证

- **前置条件**：入口配置至少两个有效脚本。
- **测试步骤**：输入 `/fav <alias1>`，再输入 `/fav <alias1>`。
- **预期结果**：第一次提示「已收藏」，第二次提示「已取消收藏」，每次均给出明确反馈。
- **验收标准**：[001]

#### MT002 无效收藏命令验证

- **前置条件**：入口存在有效脚本，准备一个不存在的别名。
- **测试步骤**：输入 `/fav`（无别名）、`/fav <不存在别名>`。
- **预期结果**：均提示别名无效或缺失，收藏状态不发生变化。
- **验收标准**：[002]

#### MT003 收藏持久化与实例一致性验证

- **前置条件**：已收藏一个脚本。
- **测试步骤**：退出并重启 azKits，再启动第二个终端实例加载同一入口，分别查看收藏。
- **预期结果**：重启后收藏保留；两个实例的收藏状态一致。
- **验收标准**：[003]

#### MT004 候选排序与去重验证

- **前置条件**：收藏脚本 A 且 A 最近运行过；最近运行过未收藏的脚本 B；另有普通脚本 C。
- **测试步骤**：输入 `/` 查看候选列表。
- **预期结果**：候选顺序为 A（收藏）、B（最近使用）、C（普通）；A 只出现一次。
- **验收标准**：[004] [005]

#### MT005 非空查询置顶验证

- **前置条件**：收藏脚本 A、最近使用脚本 B 与普通脚本 C 的别名/名称包含相同关键字。
- **测试步骤**：输入该关键字并查看候选。
- **预期结果**：匹配结果中 A、B 仍排在 C 之前，且带对应标识。
- **验收标准**：[006]

#### MT006 候选行内容验证

- **前置条件**：存在收藏脚本和最近使用脚本，含中文名称。
- **测试步骤**：输入 `/` 检查候选行。
- **预期结果**：每行显示收藏/最近使用标识、名称、简述与状态，中文无乱码。
- **验收标准**：[007]

#### MT007 最近使用更新与一键触发验证

- **前置条件**：依次成功启动脚本 A、B，再启动 A。
- **测试步骤**：输入 `/` 查看最近使用，直接按 `Enter` 触发顶部候选。
- **预期结果**：A 排到 B 之前；直接 `Enter` 再次启动 A；同一脚本只出现一次。
- **验收标准**：[008] [010]

#### MT008 最近使用实例隔离验证

- **前置条件**：两个终端实例加载不同或相同入口，其中一个实例启动过脚本。
- **测试步骤**：在另一实例输入 `/`，再重启执行过脚本的实例输入 `/`。
- **预期结果**：另一实例无该最近使用记录；重启后的实例最近使用为空。
- **验收标准**：[009]

#### MT009 键盘与 list/run 联动验证

- **前置条件**：存在收藏与最近使用脚本。
- **测试步骤**：在 TUI 用方向键选择并运行；退出后执行 `list` 与 `run <alias>`。
- **预期结果**：TUI 全程无鼠标操作；`list` 标识收藏脚本；`run` 正常运行收藏/最近使用脚本。
- **验收标准**：[011] [012] [013]

#### MT010 失效记录降级验证

- **前置条件**：收藏脚本 A 并运行过脚本 B，然后从 YAML 删除 A、重命名 B。
- **测试步骤**：重启 azKits，输入 `/` 并尝试触发失效脚本相关命令。
- **预期结果**：启动正常；失效条目不显示；操作失效脚本时给出降级提示，不崩溃。
- **验收标准**：[014]

#### MT011 空态验证

- **前置条件**：入口无收藏脚本；另准备一个无启用脚本的入口。
- **测试步骤**：分别输入 `/` 查看候选。
- **预期结果**：无收藏时不显示空收藏区；无可用脚本时显示「当前没有可用脚本」。
- **验收标准**：[015]

#### MT012 性能与离线验证

- **前置条件**：断开网络；入口含 500 个启用脚本，其中部分为收藏/最近使用。
- **测试步骤**：连续输入与删除检索字符，记录候选更新时间。
- **预期结果**：每次更新不超过 50 毫秒；全程不请求网络或 AI。
- **验收标准**：[016] [017]

#### MT013 中文与 IME 验证

- **前置条件**：中文脚本名称与收藏标识；使用中文输入法。
- **测试步骤**：组词、翻页、选字、上屏后查看候选并确认执行。
- **预期结果**：输入过程不误执行；上屏后候选正确更新；中文与标识无乱码。
- **验收标准**：[018] [019]

### 3.1 非功能需求

| 可靠性 | 失效记录不导致启动失败 | MT010 |

| 键盘效率 | 收藏/最近使用脚本最少按键触发 | MT007 |

### 3.2 实现影响提示

- 收藏与最近使用的排序逻辑需与既有斜杠候选过滤、命令历史、IME 门禁保持一致的边界。
- `/fav <alias>` 属于斜杠命令，需要与脚本别名过滤规则区分，并复用输入行、IME 与键盘状态机。
- 收藏持久化的存储位置与格式属于技术决策，不在本功能规范中限定。
- 最近使用记录需在脚本成功启动时更新，更新点与 0012「成功启动后清空输入」保持一致。
