# 0013 本次执行日志导出人工验收手册

## 验收前准备

1. 使用包含成功、失败、可终止、大量输出、中文输出的测试脚本入口启动 azKits。
2. 保留至少两个不同 YAML 入口，供多实例隔离验证。
3. 分别准备 Notepad++ 可用与不可用的环境；如需模拟编辑器均不可用或目录不可写，应在隔离测试环境操作。
4. 使用 `run_azKits_go.bat` 启动正式新版本；2026-08-12 已完成构建和配置检查，EXE 大小为 5,134,336 字节。

## MT001 成功执行日志导出

- 运行同时输出中文和英文且正常退出的脚本。
- 返回 TUI 主界面后按 `Ctrl+P`。
- 确认 2 秒内出现结果提示，文档为 UTF-8，包含集合名、脚本名与别名、起止时间、结果、退出码、stdout 和 stderr，且 TUI 显示完整路径。

## MT002 最近一次执行范围

- 依次运行输出内容明显不同的脚本 A、B。
- B 结束后按 `Ctrl+P`。
- 确认文档只有 B 的信息和输出，不包含 A。

## MT003 编辑器优先与回退

- Notepad++ 可用时导出一次，确认由 Notepad++ 打开，TUI 显示实际编辑器。
- 让 Notepad++ 不可用或启动失败后再次导出。
- 确认无需再次按键便由 Notepad 打开。

## MT004 编辑器均不可用

- 在隔离环境中使 Notepad++ 和 Notepad 均无法启动。
- 完成一次执行后按 `Ctrl+P`。
- 确认文件仍存在，TUI 同时显示导出成功、完整路径和编辑器打开失败；按路径可人工找到文件。

## MT005 无日志与运行中

- 新启动一个实例，尚未运行脚本时按 `Ctrl+P`，确认不创建文件并提示没有可导出日志。
- 启动一个持续运行脚本，在未结束时按 `Ctrl+P`，确认不导出并提示等待结束返回主界面。

## MT006 失败及终止日志

- 运行异常退出脚本，结束后导出。
- 运行可持续执行的脚本并终止，返回主界面后导出。
- 确认两份文档均包含已捕获输出、正确最终状态和可用退出码。

## MT007 写入失败

- 在隔离环境中使导出目录不可写，并准备需要保护的既有文档。
- 按 `Ctrl+P`。
- 确认 TUI 显示写入失败原因、不启动编辑器、既有文档内容不变。

## MT008 多终端实例隔离

- 同时启动 A、B 两个不同入口实例，分别运行输出可辨认的脚本。
- 两个脚本结束后在各自实例按 `Ctrl+P`。
- 确认两份文档只包含对应实例的集合、脚本和最近一次输出。

## MT009 响应与离线

- 断开网络，运行并结束一个产生大量输出的脚本。
- 按 `Ctrl+P` 并计时到 TUI 显示结果。
- 确认不超过 2 秒，文档完整，本地编辑器可打开，过程中没有网络或 AI 依赖提示。
