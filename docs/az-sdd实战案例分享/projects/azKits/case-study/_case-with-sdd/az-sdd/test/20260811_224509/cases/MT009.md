## 测试要求

1. 确认 ADB 设备连接及执行该 BAT 的业务条件满足。
2. 用上述 YAML 启动 TUI，执行 `/cfun`。
3. 观察 `at+cfun=0` 后的第一次 `pause`，确认必须按键才继续。
4. 观察 `at+cfun=1` 后的第二次 `pause`，确认必须再次按键才继续。
5. 观察查询命令后的第三次 `pause`，确认必须第三次按键才结束。
6. 确认 TUI 恢复，状态和输出可查看，并可继续执行其他命令。
