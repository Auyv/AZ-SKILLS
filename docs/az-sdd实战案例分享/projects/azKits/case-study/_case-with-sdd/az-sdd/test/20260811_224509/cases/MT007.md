## 测试要求

1. 关闭当前正在运行的 azkits 实例，在项目根目录执行 `build_azKits.bat`。
2. 执行 `dist\azkits.exe --config examples\toolbox.yaml`。
3. 确认该示例条目没有填写 `interactive`，输入 `/demo-interactive` 并按 Enter。
4. 输入任意文本并按 Enter；分别在两次 `pause` 提示出现后按键继续。
5. 确认每次提示都会等待，期间按键不会触发 TUI；脚本完成后 TUI 自动恢复。
6. 确认日志视口包含交互输出和成功状态，输入框为空且按 `↑` 可调出 `/demo-interactive`。

## 预期结果

省略 `interactive` 时仍默认进入交互模式；文本输入和两次按键等待均正常，TUI 不争抢输入，结束后恢复且保留日志、状态和历史。
