# 0200 N725A MPU 升级人工验收手册

## 前置条件

1. N725A 目标设备可恢复，供电稳定。
2. 使用与设备型号匹配的有效整包和一份可触发失败的无效包。
3. 整应用已使用 N725A 工具链构建成功并部署。
4. 可持续采集 `N725aUpgrade`、`MpuUpgrade` 和 NF 升级状态日志。

## MT004 有效整包与兼容接口

1. 将有效整包放到配置的 MPU 升级路径。
2. 发起 NF/MPU 升级并轮询进度与状态。
3. 确认提交后进度达到 100%，状态为 `WaitReboot`。
4. 记录设备是否自动重启；重启后确认厂商结果对应成功状态。
5. 确认 NF 流程继续执行，检查 A/B 活动槽位及系统同步。
6. 分别调用备份和回滚兼容接口。

预期：整包升级成功；备份和回滚立即成功且不阻塞流程；分区信息来自 SDK 真实查询。

## MT005 异常路径

1. 配置不存在的包路径后发起升级。
2. 配置无效包或使 `nwy_fota_ua()` 返回失败。
3. 查询状态、进度和错误码。

预期：不存在文件不会调用厂商升级；厂商失败映射为 `UpdateFailed` 和负错误码；应用保持可查询。

## 证据记录

- 设备型号与软件版本。
- 升级包名称及校验值。
- 升级前后活动槽位。
- 厂商升级提交、结果和损坏状态返回值。
- 自动重启、A/B 同步及 NF 后续流程结果。
