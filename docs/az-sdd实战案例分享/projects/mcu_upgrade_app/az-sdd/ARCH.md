# 项目级技术架构

## 全局技术约束

| 项目 | 当前实现基线 |
|---|---|
| 语言与构建 | C；CMake/交叉编译脚本；AC8257 Android NDK 构建入口 |
| 运行模型 | 进程创建组件后循环调用 `RunOnce`，退出时按相反顺序释放 |
| 硬件适配 | 编译期选择 AG35_ASR1806、AG35_CEVN、AR590、AG35_ASR1803、N725A 或 SIM7805 |
| 配置 | `/vendor/app/hq/etc/nfupgrade_cfg.ini` 不存在时回退默认值 |
| 关键文件 | 默认介质 `/media/card/`；升级、日志与密钥路径可配置 |
| 可观测性 | ALOG 与可滚动文件日志；NF/RFOP 状态可写入 SRT 属性 |
