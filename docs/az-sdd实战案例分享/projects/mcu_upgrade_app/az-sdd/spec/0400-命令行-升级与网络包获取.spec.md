## Part 1：功能契约

### 用户目标与场景

维护人员可通过 `hqupgrade` 命令提供本地镜像或 HTTP 地址，选择可选密钥目录，下载升级包、解包安全镜像、发起 NF 升级或查询升级状态。

### 用户流程

1. 以 `--img` 或 `--url` 提供升级包，并可选提供 `--keys-dir`。
2. 当使用 URL 时，系统下载到升级文件位置；传输中显示进度。
3. 当提供密钥目录时，系统将安全包解出为可升级文件；否则使用普通包。
4. 执行升级请求或查询当前状态。

### 输入与输出

| 输入 | 规则 | 输出 |
|---|---|---|
| `--img` | 本地文件可读取 | 升级包处理结果 |
| `--url` | HTTP URL 可连接 | 下载进度与成功/失败 |
| `--keys-dir` | 包含所需密钥文件 | 安全包解包结果 |
| 查询模式 | 不要求镜像或 URL | 当前升级状态 |

## Part 2：验收契约

## 验收标准

- [ ] [001] `--img` 或 `--url` 至少提供一个；两者均未提供时命令报告参数无效。
- [ ] [002] HTTP 下载支持连接超时、重试、进度显示和已下载内容续传。
- [ ] [003] 下载成功后，普通包可进入升级；提供密钥目录的安全包可先解包再升级。
- [ ] [004] 下载、解包或升级请求失败时，命令返回失败并输出可诊断信息。
- [ ] [005] 查询命令可显示当前升级任务的状态、百分比和错误码。

## 测试用例

### MT001 本地包升级
- **测试步骤**：用有效 `--img` 运行命令并查询状态。
- **预期结果**：包被处理，升级请求被提交，状态可读取。
- **验收标准**：[001][003][005]

### MT002 网络下载续传
- **测试步骤**：以 `--url` 下载大文件，中断后再次执行相同命令。
- **预期结果**：显示下载进度并从已存在内容继续或安全重下。
- **验收标准**：[002]

### MT003 安全包
- **测试步骤**：提供安全包与完整 `--keys-dir`。
- **预期结果**：安全包解出为升级包后再发起升级。
- **验收标准**：[003][004]
