# Markdown 与 Mermaid 规则

> 仅在创建、修改、评审或验证含 Mermaid 图的 Markdown 时加载。

## Mermaid 兼容与写法

- Mermaid 图必须兼容 Mermaid 10.1.0，避免使用仅在更高版本支持的语法。
- `flowchart` 的边标签统一以双引号包裹：`A -->|"中文标签"| B`。
- 中文、空格、斜杠、标点或其他特殊字符不得作为未加引号的边标签。
- 节点文本包含中文、空格、路径、斜杠、括号或 HTML 换行时，使用 `NODE["节点文本<br/>第二行"]` 形式。

## 交付验证

- 交付前检查 Mermaid 代码围栏成对。
- 检查所有 `-->|...|`、`--|...|`、`-.->|...|`、`<-->|...|` 边标签均已使用双引号。
- 条件允许时，使用目标渲染器或兼容版本实际渲染验证。
- 渲染失败时保留原始错误信息，按错误行定位并修正语法；截图正常或其他渲染器可用不能代替目标版本验证。
