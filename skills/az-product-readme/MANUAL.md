# az-product-readme 手工使用指南

1. 收集产品一句话用途、支持范围、主入口、唯一输入、输出文件和退出码。
2. 运行一次真实示例，保存 GUI、命令行或报告截图；连续操作优先制作 3 到 4 秒 GIF。
3. 用文本格式 SVG 画两张核心图：首屏“输入 → 引擎 → 输出 + 核心原则”总览图，流程章节带产物和分支的阶段图。图里只写已验证的名称和产物，图片之后配逐条文字解释。
4. 依照 `SKILL.md` 的章节顺序写 README，先让用户看懂价值，再给出最短上手路径；删除与图片重复的 ASCII 流程。
5. 用一条真实异常记录说明定位过程，明确风险状态和复扫动作。
6. 检查编码、代码围栏、图片路径、产品名、脚本名和发布包名称；SVG 渲染成位图后确认无文字截断和元素重叠。

不要把内部实现文件、构建细节或未经验证的平台支持塞进快速上手路径。用户只需要知道提供什么、如何执行、会得到什么，以及异常时如何处理。
