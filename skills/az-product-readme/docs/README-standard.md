# README 发布检查清单

## 首屏

- 有一句话价值、适用对象和当前支持范围。
- 有真实视觉：流程图、GUI、终端或报告截图。
- 连续操作使用轻量 GIF，帧数和文件体积可控。

## 图示

- 流程、架构、状态机描述用 SVG 图片展示，文字解释放图片之后。
- README 中不保留与图片重复的 ASCII 流程。
- 图示中的技能名、命令、产物名与代码事实一致，图例含义有说明。
- SVG 为合法 XML，渲染成位图后无文字截断、无元素重叠。
- 图片随版本同步：入口、阶段或产物名称变更后更新图示。

## 上手

- 写清前置条件、唯一输入和推荐入口。
- GUI 与 CLI 命令与发布包实际文件名一致。
- 用户无需关心内部构建制品和解析细节。

## 结果与风险

- 写清报告位置、文件类型和用途。
- 有真实报告截图和异常定位示例。
- 定义 PASS、WARNING、REVIEW、FAIL、IGNORED 与退出码。
- 明确 `REVIEW` 的原因和行动建议。
- 明确风险退出码不等于工具执行错误。

## 发布前验证

- README 为 UTF-8，Markdown 围栏成对，所有资源引用存在。
- 实际运行入口并确认报告或预期风险退出码。
- 产品名、GUI、报告、脚本、截图和 GIF 一致。
- 当前版本边界真实、清晰、无过度承诺。
