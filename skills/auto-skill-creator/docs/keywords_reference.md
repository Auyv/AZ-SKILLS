# 关键词参考列表

本文档列出了 `auto-skill-creator` 技能使用的关键词，用于检测用户的满意/不满意信号。

## 正向关键词

表示用户满意、问题已解决的关键词：

### 常用中文

| 关键词 | 说明 |
|--------|------|
| 搞定 | 表示任务完成 |
| 可以了 | 表示可以接受 |
| 没问题 | 表示没有问题 |
| 解决了 | 表示问题已解决 |
| 完美 | 表示非常满意 |
| 👍 | 点赞表情 |
| 感谢 | 表示感谢 |
| 不错 | 表示还行 |
| 很好 | 表示满意 |
| 棒 | 表示非常好 |

### 常用英文

| 关键词 | 说明 |
|--------|------|
| good | 好的 |
| ok / okay | 可以 |
| done | 完成了 |
| finished | 完成了 |
| success | 成功 |
| solved | 已解决 |
| great | 太棒了 |
| perfect | 完美的 |
| excellent | 优秀的 |

### Emoji

| 关键词 | 说明 |
|--------|------|
| 👍 | 点赞 |
| 👌 | OK手势 |
| ✨ | 闪闪发光（表示满意） |
| 🎉 | 庆祝（表示庆祝成功） |
| ✅ | 对勾（表示完成） |

## 负向关键词

表示用户不满意、有问题的关键词：

### 常用中文

| 关键词 | 说明 |
|--------|------|
| 不行 | 表示不可行 |
| 失败了 | 表示操作失败 |
| 报错 | 表示出现错误 |
| 不对 | 表示不正确 |
| 没用 | 表示没有效果 |
| 垃圾 | 表示非常不满意 |
| 烂 | 表示质量差 |
| 错误 | 表示有错误 |
| bug | 表示有缺陷 |
| 问题 | 表示有问题 |

### 常用英文

| 关键词 | 说明 |
|--------|------|
| failed | 失败 |
| error | 错误 |
| issue | 问题 |
| problem | 问题 |
| broken | 坏了 |
| wrong | 错误的 |
| bad | 不好的 |

## 添加新关键词

### 通过对话添加

在对话中直接说：
- "把'xxx'加到正向关键词里"
- "把'xxx'加到负向关键词里"

### 手动编辑

编辑 `config/skill-creator-config.json` 文件：

```json
{
  "positive_keywords": ["原有关键词", "新关键词"],
  "negative_keywords": ["原有关键词", "新关键词"]
}
```

## 关键词匹配规则

1. **大小写不敏感**：检测时自动转换为小写比较
2. **模糊匹配**：关键词可以出现在句子的任意位置
3. **支持表情**：Emoji 作为关键词也能被检测

## 注意事项

- 关键词列表会持续扩展
- 建议定期查看并清理无用的关键词
- 避免添加过于通用的词汇（如"好的"可能过于宽泛）
