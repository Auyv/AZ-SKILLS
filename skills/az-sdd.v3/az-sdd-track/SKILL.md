# AZ-SDD-TRACK

状态追踪 - 管理和更新项目工作状态。

## 执行步骤

### Step 1: 检查环境

```
1. 检查 az-sdd/ 目录是否存在
   → 不存在：提示先执行 /az-sdd-init
   → 存在：继续
2. 读取 track.md
3. 读取 SPEC.md 获取功能状态统计
```

### Step 2: 显示状态总览

```
📊 项目状态总览

## 功能进度
| 状态 | 数量 |
|------|------|
| 草稿 | 1 |
| 开发中 | 2 |
| 测试中 | 1 |
| 待验收 | 1 |
| 已完成 | 3 |

## 进度条
[████████░░░░░░░░░░░░░░░] 50% (3/6)

## 今日工作
- 
```

### Step 3: 根据参数执行

**如果带参数**（如查看特定功能状态）：
```
→ 显示指定功能的状态详情
→ 显示历史变更记录
```

**如果无参数**：
```
→ 显示状态总览
→ 询问用户需要执行的操作
```

### Step 4: 提供操作选项

```
请选择操作：

1. 📋 查看所有功能状态
2. 📈 查看进度统计
3. ✏️ 记录今日工作
4. ⚠️ 记录问题
5. 📝 其他更新

或者直接告诉我你想做什么。
```

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| az-sdd/ 不存在 | 提示先执行 /az-sdd-init |
| track.md 不存在 | 自动创建 |
| 用户无操作需求 | 显示状态后结束 |
