# 解析规则

## 1. 章节识别规则

### 1.1 模块标题（一级分类）

**正则**：`^### 3\.\d+\. (.+)$`

**示例**：
```
### 3.3.1. TrustZone RSA加密和解密
### 3.3.2. TrustZone AES 加密和解密
```

**提取**：`TrustZone RSA加密和解密` 作为模块名

### 1.2 函数标题（二级分类）

**正则**：`^### 3\.\d+\.\d+\. (\w+)$`

**示例**：
```
### 3.3.1.1. QTEE_RSA_init
### 3.3.2.5. qtee_aes_128_ecb
```

**提取**：函数名 + 章节号

### 1.3 函数原型

**正则**：
- `^### (\w+\s*\*?\w+\([^)]*\))$`  - 函数原型
- `^(int|void|char\s*\*|uint\d+_t\s*\*?|QTEE_\w+\s*\*)\s+\w+\([^)]*\)`  - 返回值

**示例**：
```
### QTEE_RSA *QTEE_RSA_init(void)
### int qtee_rsa_encrypt(QTEE_RSA_CTX *rsa_arg)
```

**提取**：函数签名

## 2. 参数识别规则

### 2.1 参数定义

**正则**：`^([a-zA-Z_][a-zA-Z0-9_]*)\s*[:：]\s*$`

**示例**：
```
rsa_arg：
key：
inbuf：
```

**提取**：参数名（描述在后续行）

### 2.2 参数方向

**正则**：`\[(In|Out|In/Out)\]`

**示例**：
```
[In] 指向OpenSSL RSA密钥的指针。
[Out] 指向QTEE-RSA密钥的指针。
[In/Out] 指向QTEE_RSA_CTX结构体的指针。
```

**提取**：参数方向

### 2.3 参数描述

紧跟参数方向后的中英文文本，直到遇到下一个参数或空行。

## 3. 返回值识别规则

### 3.1 成功值

**正则**：`^0\s+函数执行成功$`

**示例**：
```
0 函数执行成功
```

### 3.2 失败值

**正则**：`^负值\s+函数执行失败.*$`

**示例**：
```
负值 函数执行失败。例如，-3表示内存空间不足。
```

### 3.3 特殊返回值

| 模式 | 含义 |
|------|------|
| `空\s+函数执行失败` | 返回 NULL |
| `函数执行成功。详见第X章。` | 返回结构体指针 |

## 4. 结构体识别规则

**正则**：`^typedef\s+struct\s*\{`

**示例**：
```c
typedef struct {
    uint32_t padding_type;
    uint8_t *inbuf;
    ...
}QTEE_RSA_CTX
```

**提取**：结构体名、成员列表

## 5. 枚举识别规则

**正则**：`^typedef\s+enum\s*(\{)?`

**示例**：
```c
typedef enum {
    QTEE_SUCCESS = 0,
    QTEE_ERR_FAILURE = 1,
    ...
}QTEE_ERROR_TYPE
```

**提取**：枚举名、枚举值列表

## 6. 宏定义识别规则

**正则**：`^#define\s+(\w+)\s+(.+)$`

**示例**：
```c
#define QTEE_AES_MAGIC "#QLAES#"
#define QTEE_AES_MAX_BITS 256
#define QTEE_AES128_KEY_SIZE 16
```

**提取**：宏名 + 宏值

## 7. 错误码识别规则

**正则**：`^(\w+)\s*=\s*(\d+),?$`

**示例**：
```
QTEE_SUCCESS = 0,
QTEE_ERR_FAILURE = 1,
```

**提取**：枚举值名 + 数值

## 8. 排除规则

以下内容**不**应作为 API 提取：

| 内容 | 原因 |
|------|------|
| 目录页（"目录"+"...."） | 非内容 |
| 修订记录 | 非 API |
| 前言/版权声明 | 非 API |
| 页眉页脚乱码 | OCR 错误残留 |
| 表格索引 | 非内容 |

## 9. 多模态适配

针对 Quectel 不同子模块的 API 参考手册，主要差异：

| 文档 | 章节命名 | 函数命名风格 |
|------|---------|-------------|
| QTEE API | 3.3.1, 3.3.2, 3.3.3, 3.3.4 | `QTEE_*` / `qtee_*` |
| SMS API | 3.1, 3.2, ... | `ql_sms_*` |
| SIM API | 3.1, 3.2, ... | `ql_sim_*` |
| GPIO API | 3.1, 3.2, ... | `ql_gpio_*` |
| UART 应用指南 | 1, 2, 3, ... | `ql_uart_*` |

**统一处理**：基于正则 `^\d+\.\d+\.\d+\.` 提取章节号，函数名按字母排序聚合同名变体。
