## 0. 接口规范总则

### 0.1 基础约定
| 项 | 规范 |
|---|---|
| Base URL | `{base_url}` |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 时间格式 | ISO 8601 |

### 0.2 鉴权
- 除登录接口外，**所有 API 必须在请求头带 JWT Token**：
  ```
  Authorization: Bearer <token>
  ```

### 0.3 统一响应格式

#### 成功响应
```json
{
  "code": 0,
  "message": "ok",
  "data": { ... }
}
```

#### 失败响应
```json
{
  "code": 4001,
  "message": "错误信息",
  "data": null
}
```

### 0.4 错误码规范
| 段 | 含义 |
|---|---|
| 0 | 成功 |
| 1xxx | 通用错误 |
| 2xxx | 认证错误 |
| 3xxx | 权限错误 |
| 4xxx | 资源错误 |
| 5xxx | 业务错误 |
| 9xxx | 服务端错误 |

### 0.5 HTTP 状态码 vs 业务码
- HTTP 状态码：网络层成败
- **业务码**：业务成败（在 body 里）

### 0.6 分页约定
- 请求参数：`page`（从 1 开始）、`page_size`（默认 20）
- 响应：
  ```json
  "data": {
    "items": [...],
    "total": 123,
    "page": 1,
    "page_size": 20
  }
  ```
