# 网络连接异常初步排查

## 典型场景

```
NetOpen打开失败, 日志显示返回值为 -3
ATChipNetOpen(0) Error: -3 (@ref ATC_TResult)
```

---

## Step 1: 获取 SIM ICCID

确认模组能否识别 SIM 卡

| 查询方式 | 命令 | 正常响应示例 |
|----------|------|--------------|
| AT 方式 | `at+iccid` | ICCID: 898601... |
| SRT 方式 | `srtget 306` | ICCID 值 |

**判断**：ICCID 能正常获取 = SIM 卡被模组正常识别

---

## Step 2: 自测设备状态

### 2.1 SIM 卡状态
```
命令: srtget 307
响应: 0 - 未插卡
      1 - 卡有效且正常
      2 - 卡被锁
      3 - 卡无效
```

### 2.2 飞行模式检查
```
命令: at+cfun?
响应: +CFUN: 1  → 模组正常工作
      +CFUN: 0  → 飞行模式，需关闭
```

### 2.3 信号强度
```
命令: at+csq
响应: +CSQ: <rssi>,<ber>
      rssi 范围 0~31，值越大信号越好
      通常 <16 网络会时断时续
      99 表示无信号
```

### 2.4 注网状态
```
命令: at+creg?
响应: +CREG: 0,1  → 已注册本地网络
      +CREG: 0,5  → 已注册漫游网络
      其他值 → 未注册
```

### 2.5 运营商信息
```
命令: at+qnwinfo
命令: at+cops=?

确认是否为项目指定的运营商
```

### 2.6 APN 配置
```
命令: AT+CGDCONT?
查询当前模组配置的 APN

MCU 默认 APN: srtget 8

MPU 实际生效 APN（仅移远 AG35 模组）:
ql_cmd nf get data_call all class=config

判断: MCU 端 APN ⊆ MPU 端 APN → 正常
```

---

## Step 3: 提供信息给项目经理

向 @项目经理 提供以下信息：

1. **ICCID** — 用于向运营商确认卡状态
2. **APN 配置对比结果** — MCU vs MPU
3. **信号强度和注网状态**

项目经理协助确认：
- [ ] SIM 卡是否已正常开通
- [ ] 是否存在白名单限制
- [ ] 是否需要配置特定 APN
- [ ] 是否需要指定运营商

---

## NetOpen 失败主要原因

| 原因 | 排查方向 | 处理方式 |
|------|----------|----------|
| 设备无信号 | 检查天线连接 | 确认天线装配 |
| 模组处于飞行模式 | 关闭飞行模式 | at+cfun=1 |
| SIM 卡无法注网 | 向运营商确认 | 卡状态/白名单/APN/运营商限制 |
